Otevřený komentář k zákonu o kategorizaci zdravotnických prostředků na poukaz — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; kategorizační strom, úhradové skupiny, preskripční a indikační omezení, úhradové limity, přechodná ustanovení, změna zákona o veřejném zdravotním pojištění a příloha (oddíly A–C).

Konsolidované znění: dokument e-Sbírky `SB-2025-00288_2026-01-01`.
